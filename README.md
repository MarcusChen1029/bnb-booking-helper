# 民宿訂房小幫手（展示版）

用簡單的網頁畫面操作民宿訂房和記帳，並可預覽資料在 Excel 檔裡的樣子。

## 功能

- **總覽**：本月住房收入、住房率、淨利、尚未收款；今天入住、退房、住宿中、未來 7 天的訂房；重複訂房和未結清的提醒
- **訂房**：搜尋、篩選，新增或修改訂房，自動算出晚數、平日／假日房價、應收、未收和平台抽成，重複訂房會即時警告
- **房況**：每月房況表，點空格就能新增訂房
- **收支**：記錄其他收入和支出，顯示每月收支和淨利
- **預覽 Excel**：以唯讀方式顯示 Excel 檔的各個工作表（訂房紀錄、收支記帳、房況月曆、月報表、設定），包含在網頁上做的修改

## 展示版說明

- 打開網頁就會自動載入範例資料，不能開啟或下載 Excel 檔
- 修改只存在這個頁面，重新整理就會還原
- 正式版可以開啟自己的 Excel 檔，在 Chrome、Edge 上直接存回原檔

## 計算規則

和 Excel 公式相同：週五、週六晚為假日價；住房收入和平台抽成依入住日歸月；住房率依實際住宿天數跨月拆分。
