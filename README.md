# 民宿訂房小幫手

用簡單的網頁畫面操作「民宿訂房記帳表」Excel 檔（展示版）：新增訂房、看房況、記帳，存檔後 Excel 裡的公式、月曆和月報表都會自動更新。

## 功能

- **總覽**：本月住房收入、住房率、淨利、尚未收款；今天入住、退房、住宿中、未來 7 天的訂房；重複訂房和未結清的提醒
- **訂房**：搜尋、篩選，新增或修改訂房，自動算出晚數、平日／假日房價、應收、未收和平台抽成，重複訂房會即時警告
- **房況**：每月房況表，點空格就能新增訂房
- **收支**：記錄其他收入和支出，顯示每月收支和淨利

## 使用方式（展示版）

這是展示版，打開網頁就會自動載入範例資料，不能開啟其他 Excel 檔。

1. 打開網頁，直接新增或修改訂房、記帳
2. 按「下載 Excel」，可以下載包含修改內容的 Excel 檔，在 Excel 裡確認公式、月曆和月報表都跟著更新
3. 重新整理網頁就會還原成原本的範例資料

正式版可以開啟自己的 Excel 檔，在 Chrome、Edge 上直接存回原檔。

## 技術說明

- 用 [JSZip](https://stuk.github.io/jszip/) 讀寫 .xlsx，只修改「訂房紀錄」和「收支記帳」工作表中需要填寫的儲存格，其他內容（公式、格式、圖表、下拉選單）完全保留
- 存檔時設定 `fullCalcOnLoad`，Excel 開啟時會重新計算所有公式
- 網頁上的計算規則和 Excel 公式相同：週五、週六晚為假日價；住房收入依入住日歸月；住房率依實際住宿天數跨月拆分
- 房間、房價、訂房管道和收支類別請在 Excel 的「設定」工作表修改
